v2.0 — 2026-04-09
────────────────────────────────────────────────────────────────

NEW — Hookshot bridge
  Webhooks, GitHub, GitLab, RSS/Atom feeds, Figma, JIRA.
  No external database — uses Matrix state as store.
  Generates passkey.pem (RSA 4096), writes config.yml and
  registration.yml from scratch. Proxy guide shown post-install
  for Caddy, NPM, and Traefik.
  Bot: @hookshot:domain — !hookshot webhook / !hookshot feed

NEW — Repair wizard (menu option 9)
  Detects installed stack, shows live container status and
  well-known health, guided repair for:
    Synapse / MAS / PostgreSQL not running
    Well-known broken or wrong HTTP code
    Calls not working (LiveKit / TURN / firewall)
    Reverse proxy not routing (Caddy / NPM / Traefik)
    Admin panel 404 / not reachable
    Element Web loading wrong homeserver
    Bridge not connecting / bot unresponsive
    Restart all containers
  Post-repair status check runs automatically.

NEW — Migrate Well-Known (reconfigure option 6)
  Auto or guided mode to switch how well-known is served.
  Auto mode: rewrites Caddyfile + reloads, generates
  npm-wellknown.conf, or writes static files.
  Three directions: inline respond → files, files → inline,
  or refresh/repair both.

NEW — NPM auto proxy-host creation
  After install, all proxy hosts created via NPM REST API.
  SSL method prompt (Let's Encrypt or HTTP-only).
  Well-known location blocks injected into base domain host.
  Wait loop polls port 80 (reliable signal NPM nginx is up).
  Falls back gracefully to manual guide if auth fails.

FIX — NPM port conflict detection
  Identifies what is holding ports 80/443 (old NPM, Caddy,
  Traefik, or other). If old NPM detected, offers to stop it
  and reuse standard ports — no more forced fallback to 8000/8443.

FIX — Uninstall now actually removes containers
  _delete_single_stack rewritten: docker compose down as primary,
  then scans by compose project label + all known container names.
  NPM (jc21/nginx-proxy-manager) and Hookshot added to orphan
  scanner image pattern.

FIX — Orphan cleanup on no-stack-dir uninstall
  When find_all_matrix_stacks returns nothing, falls through to
  scan_and_remove_matrix_resources instead of silently returning.

FIX/UPGRADE — Telegram bridge (now Go)
  dock.mau.dev/mautrix/telegram:latest main branch is now the Go
  rewrite. Treated identically to all other Go bridges: binary
  search via command -v, config at /pkg/connector/example-config.yaml,
  top-level api_id/api_hash keys, standard --entrypoint -g
  registration generation.

FIX — MAS config.yaml directory guard
  Removes config.yaml if it was created as a directory by a
  previous failed install. Also guards compose.yaml, homeserver.yaml,
  livekit.yaml.

FIX — Compose output suppressed
  docker compose up/down no longer prints TUI to terminal.
  Output goes to the deployment log file instead.

FIX — Caddy well-known backtick syntax (issue #12)
  respond blocks use backtick syntax. Single quotes caused
  Caddy to return literal ' characters instead of JSON.

FIX — Diagnostics hang
  docker stats: timeout 15s. docker logs per container: timeout 8s.

FIX — VPN guide opt-in
  Long VPN guide shown only if user requests it.

FIX — Cleanup uses y/n, uninstall uses TYPE DELETE
  scan_and_remove confirmation changed to y/n.
  Uninstall proper still requires typing DELETE.

FIX — System package upgrade prompt (all distros)
  ask_yn before upgrading. Default yes.

FIX — DuckDNS token visible input
  Shows masked confirmation: first4****last4 (N chars).

FIX — S3 warning updated
  Explicitly lists Google Drive, Dropbox, OneDrive, NFS, SMB
  as not S3-compatible.

FIX — NPM/NPMPlus label conditional
  NPMPlus shown only when user selects existing proxy.

FIX — Port conflict message generic
  Names actual detected service, not hardcoded Caddy/Traefik.
